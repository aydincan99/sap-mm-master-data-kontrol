# Sample data

Synthetic SAP MM-style fixtures for reproducing K1–K6 findings. Not a live system extract.

| File | Role |
|---|---|
| `urun_kodlari.xlsx` | Sellable product codes (types 6/7) |
| `ust_kodlar.xlsx` | Parent / reference codes (`RC…`, type 15) |
| `marm.xlsx` | Alternative units of measure (counters) |

Copy these three files next to the Python script, then run the engine. See the root README for commands.
